# Assets and dependencies

- `delivery-rider.png`: generated orange scooter/rider illustration created for this project. Included locally; no remote image call at runtime.
- Four food photographs are illustrative samples, downloaded from Unsplash image endpoints; dishes in the sample menu may not exactly match the photographs.
  - burger: https://images.unsplash.com/photo-1568901346375-23c9450c58cd
  - pizza: https://images.unsplash.com/photo-1513104890138-7c749659a591
  - salad: https://images.unsplash.com/photo-1512621776951-a57141f2eefd
  - rice: https://images.unsplash.com/photo-1603133872878-684f208fb84b
- `favicon.svg`, layouts, CSS parcel and animation are part of this project source.
- Gson 2.13.2 is included under the Apache License 2.0. Its license metadata is retained in the JAR; https://github.com/google/gson .
- The Java HTTP server and password cryptography are JDK APIs.
- Kitchen/city/parcel/lid/road scene elements are CSS from this project.
